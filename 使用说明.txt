推文台账助手 — 使用说明
========================================

【第一次用】
1. 双击「启动.cmd」→ 会自动打开浏览器 http://127.0.0.1:8770
2. 点页面上的「换一个文件」，选你的台账 Excel（.xlsx）
   （微信收到的表格是只读的，程序会自动复制一份工作副本再动笔，原文件不动）

【日常用法】
- 单条录入：粘一篇公众号文章链接，自动补齐 13 个字段，缺的会标红让你补。
- 批量导入：点「链接池」标签，把一堆链接整段粘进去，或导入一张全是链接的 Excel。
- 桌面悬浮按钮：双击「启动悬浮按钮.cmd」，桌面右侧出现「记」字圆钮。
    打开要记的那篇推文 → 鼠标移上圆钮 → 点「抓取链接」。
    微信客户端里的文章没有地址栏：先点文章右上角 ⋯ →「复制链接」，再点「抓取链接」。
- 退出悬浮：点「退出」回到网页看缓存，勾选后一次性写进台账。

【关闭】
双击「停止.cmd」即可（关闭服务窗口也等于停止）。

【环境要求】
Windows + Python 3.9+（需要 openpyxl，没有就在命令行跑：pip install openpyxl）

详细说明见 README.md；出错时看 data\floater.log（每次抓取的判定过程都写在这里）。
